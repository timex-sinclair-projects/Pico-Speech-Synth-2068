# Text to allophones (Phase 2)

Two engines behind one interface, `tts_speak(engine, text, emit, ctx)`,
streaming SP0256-AL2 allophone codes to a callback. No allocation; the
largest stack object is the 512-byte phoneme buffer of the NRL path.

| | NRL | CTS256 |
|---|---|---|
| Rules | 355, from John A. Wasser's `english.c` (1985, public domain), the NRL Report 7948 letter-to-sound rules | 432, extracted from the GI CTS256A-AL2 ROM by Michel Bernard (GPL-3.0) |
| Rule output | phonemes, mapped to allophones by `phon2allo.c` using the datasheet's Table 5 positional rules | allophones directly, positional choices baked into the rules |
| Numbers | cardinals, ordinals (1st, 22nd), decimals, `$12.50` | digit by digit, as the chip did |
| Punctuation | `,` `;` PA4; `:` PA5; `.` `!` `?` PA5 PA5; other symbols spoken by name | the chip's table: space PA2, `,` PA4, `.` PA5 PA5, `%` `$` `#` spoken, `-` PA1 |
| Word gap | PA3 | PA2 |
| Character | closer to the datasheet's own transcriptions | the "Radio Shack" voice, quirks included (e.g. `PLEASE` → `PP EL IY ZZ`) |

Both consult `lexicon.c` first: a small exception table seeded from the
datasheet dictionary and a few project words (SINCLAIR, TIMEX, ZX).

## Files

- `rules.[ch]` — the matcher. A rule is `LEFT[MATCH]RIGHT=OUTPUT`; symbols are documented in `rules.h`. Rules are grouped by the first character of MATCH and tried in order; first match wins.
- `rules_nrl.c`, `rules_cts.c` — generated by `../tools/gen_rules.py` from `../reference/`. Do not edit by hand; edit the reference tables or the generator.
- `phon2allo.[ch]` — Wasser phonemes → allophones, with vowel+R merging (AR OR XR YR), syllabic L (EL), TT1/TT2, DD1/DD2, BB1/BB2, KK1/2/3, GG1/2/3, HH1/2, NN1/2, YY1/2, RR1/2, ER1/2, UW1/2, SS doubling and the PA2/PA3 stop pauses.
- `nrl_numbers.[ch]` — Wasser's `saynum.c` and `spellwor.c`, ported.
- `lexicon.[ch]` — exception dictionary.
- `tts.[ch]` — tokenizer and front end for both engines.

## Trying it

```sh
cd ../harness && make say
./say -e nrl "The quick brown fox jumps over the lazy dog."
./say -e cts -r ../rom/sp0256-al2.bin -o fox.wav "The quick brown fox."
```

`-t` and `-p` set speed and pitch, `-c` the clock, as in `harness`.

## Known gaps

- Wasser's table lacks a few rules the CTS256 has (e.g. `*[OW]N → AW`, so
  "brown" comes out "brone" on NRL). The generator makes it easy to add a
  correction table on top of the reference rules; the lexicon is the quick fix.
- No stress information, so the datasheet's "double the stressed short
  vowel" advice is not applied on the NRL path; CTS256 doubles where its
  rules say so.
- The CTS256's lower-case bug (its `FETCH` skipped upper-casing) is not
  reproduced; input is upper-cased first.
